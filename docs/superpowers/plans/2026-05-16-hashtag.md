# Hashtag Feature Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract `#word` tokens from post content, store them on the entity, surface them as linked segments in the view layer, and persist them in MongoDB.

**Architecture:** Mirrors the `@mention` implementation exactly. The entity owns extraction (static regex method + `Hashtags` collection). Interactors call `ExtractHashtags` and pass results to factory methods. The Presenter's `SegmentContent` method is extended to match both patterns in one pass, emitting `PostContentSegment` records with a new `HashtagText` field. The web `PostContent.razor` component renders hashtag segments as `/search?tag=` links.

**Tech Stack:** C# / .NET 10, xUnit, FluentAssertions, MongoDB (infrastructure only), Blazor (web layer)

- [ ] **Step 3: Update `SegmentContent` in `PostPresenters.cs`**

Replace the entire `PostPresenterMapping` static class:

```csharp
internal static class PostPresenterMapping
{
    private static readonly Regex TokenPattern = new(@"(@[a-zA-Z0-9_]+)|(#\S+)", RegexOptions.Compiled, TimeSpan.FromSeconds(1));

    public static PostSummaryViewModel ToViewModel(PostSummaryResponse p) => new(
        p.Id,
        p.AuthorHandle,
        SegmentContent(p.Content, p.Mentions, p.Hashtags),
        p.ParentPostId,
        p.OriginalPostId,
        p.CreatedAt,
        p.LikeCount,
        p.LikedByCurrentReader,
        p.RepostCount,
        p.RepostedByCurrentReader,
        p.QuotedPost is null ? null : new(p.QuotedPost.Id, p.QuotedPost.AuthorHandle, p.QuotedPost.Content, p.QuotedPost.CreatedAt, p.QuotedPost.Media?.Select(m => new PostMediaSummaryViewModel(m.AssetId, m.Kind, m.ContentType, m.ByteLength, m.Width, m.Height, m.DurationMs, m.SortOrder, m.ThumbnailKey, m.AltText, null)).ToArray()),
        p.Media?.Select(m => new PostMediaSummaryViewModel(
            m.AssetId,
            m.Kind,
            m.ContentType,
            m.ByteLength,
            m.Width,
            m.Height,
            m.DurationMs,
            m.SortOrder,
            m.ThumbnailKey,
            m.AltText,
            null)).ToArray() ?? Array.Empty<PostMediaSummaryViewModel>());

    internal static IReadOnlyList<PostContentSegment> SegmentContent(string content, IReadOnlyList<string>? mentions, IReadOnlyList<string>? hashtags)
    {
        var segments = new List<PostContentSegment>();
        var sequence = 0;
        var lastIndex = 0;
        var mentionSet = new HashSet<string>(mentions ?? Array.Empty<string>(), StringComparer.OrdinalIgnoreCase);
        var hashtagSet = new HashSet<string>(hashtags ?? Array.Empty<string>(), StringComparer.OrdinalIgnoreCase);

        foreach (Match match in TokenPattern.Matches(content))
        {
            if (match.Index > lastIndex)
                segments.Add(new(sequence++, content[lastIndex..match.Index], null));

            if (match.Groups[1].Success)
            {
                // @mention group
                var handle = match.Groups[1].Value[1..]; // strip leading @
                segments.Add(new(sequence++, match.Value, mentionSet.Contains(handle) ? handle : null));
            }
            else
            {
                // #hashtag group
                var tag = match.Groups[2].Value[1..]; // strip leading #
                segments.Add(new(sequence++, match.Value, null, hashtagSet.Contains(tag) ? tag : null));
            }

            lastIndex = match.Index + match.Length;
        }

        if (lastIndex < content.Length)
            segments.Add(new(sequence, content[lastIndex..], null));

        return segments;
    }
}
```

Also remove the now-unused `MentionPattern` field from `PostPresenterMapping` (it was replaced by `TokenPattern`).

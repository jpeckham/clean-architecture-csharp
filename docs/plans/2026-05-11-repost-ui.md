# Repost UI Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build feed UI support for reposting other users' posts once, with optional quote content, repost counts, highlighted current-user state, and delete-my-repost behavior.

**Architecture:** Keep reposts inside `SocialApp.Post` as posts with `OriginalPostId`, then enrich feed summaries with repost metadata and quoted original post data. The API exposes small repost endpoints and the Blazor feed renders/acts on the presenter view models.

**Tech Stack:** C#/.NET, xUnit, FluentAssertions, ASP.NET Core Minimal APIs, Blazor WebAssembly, CSS.
